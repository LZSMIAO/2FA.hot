Textures are Minecraft assets from Mojang/Microsoft, not covered by the project's code license.
Each face lists the official PNG it came from — size, SHA-1 and download URL — then the WebP the site serves, re-encoded at quality 85, which cuts the transfer by about 83%.
All backgrounds start paused on desktop and mobile, including after refresh. Playback starts only when requested. The selected scene is remembered in a cookie. Only the active scene is loaded; switching preloads all six faces before replacing it. While playing, the panorama rotates locally once every 180 seconds. Warm light and vignette overlays supplement the lighting already captured in the images; this is not a live ray-traced game world. Hidden tabs pause animation and reduced-motion preferences show a still panorama. A visitor can also upload their own background — one still image, or six faces in panorama_0–5 order — which is kept only in that browser's IndexedDB and is never sent to the server.
