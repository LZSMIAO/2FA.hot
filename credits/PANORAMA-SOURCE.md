Textures are Minecraft assets from Mojang/Microsoft, not covered by the project's code license.
All backgrounds start paused on desktop and mobile, including after refresh. Playback starts only when requested. The selected scene is remembered in a cookie. Only the active scene is loaded; switching preloads all six faces before replacing it. While playing, the panorama rotates locally once every 180 seconds. Warm light and vignette overlays supplement the lighting already captured in the images; this is not a live ray-traced game world. Hidden tabs pause animation and reduced-motion preferences show a still panorama.
