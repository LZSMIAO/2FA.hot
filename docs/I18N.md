# 多语言 / Internationalization

网站提供 30 种语言：简体中文、繁體中文、English、Español、Français、Deutsch、Português（巴西）、Русский、日本語、한국어、العربية、हिन्दी、বাংলা、اردو、Bahasa Indonesia、Bahasa Melayu、Tiếng Việt、ไทย、Türkçe、Italiano、Nederlands、Polski、Українська、فارسی、עברית、Kiswahili、Filipino、தமிழ்、తెలుగు、Ελληνικά。

## 使用行为

- 首次访问按浏览器语言选择；无法匹配时使用英语。用户选择保存在 `2fa-hot-language` Cookie 中，仅保存语言代码。
- 词典保存在 `i18n/locales/`，由 Nuxt i18n 按需加载，不在使用时请求 Google 翻译或其他翻译服务。
- 使用 `prefix_except_default` 路由策略：英语为 `/`，其他语言使用独立前缀，例如 `/zh-CN`、`/ja`。首页根路径按浏览器语言检测；独立取码页由服务端按已保存的语言选择、浏览器语言、英语回退的顺序选择语言，带语言前缀的取码链接也适用。其他明确带语言前缀的页面保持稳定。
- 片段链接使用 `/2fa#SECRET`，密钥和可选验证参数都在片段内。路径链接 `/2fa/:secret` 会先发送密钥，再显示隐私提示；语言重定向保留片段，前端加载后读取。仅切换语言时保留当前表单输入和验证参数；刷新或离开工具不新增持久化。
- 关于页提供繁体中文、简体中文和英文；指南提供简体中文和英文。仅为各页面实际提供的语言创建路由与 hreflang。其他语言从页脚进入对应英文或简体中文内容；在这些页面选择尚未翻译的语言，会进入所选语言的工具首页。
- 通行密钥安装与使用页提供简体中文、繁体中文和英文，文案维护在 `shared/passkeys-copy.ts`；其他语言的导航链接进入英文版。浏览器扩展自身的界面目前为简体中文。
- 阿拉伯语、波斯语、希伯来语和乌尔都语设置 `dir="rtl"`；密钥、URL、验证码和倒计时保持从左向右显示。
- 密钥、用户自定义标签和备注不翻译。教学、帮助、隐私说明、错误提示和无障碍标签属于界面文案，随语言切换。

## 维护词典

1. 修改或补充 `i18n/locales/zh-CN.json` 中的源消息，并同步其他语言。每种语言必须拥有相同的消息键。
2. 保留 `{count}`、`{period}` 等占位符的名称。可以根据语法调整其顺序，不可删除或翻译参数名。
3. 运行 `node scripts/sync-message-keys.mjs` 同步 `shared/message-keys.ts`，再运行 `pnpm format`。源消息映射独立于 locale JSON，避免将 Nuxt 编译后的消息函数误作原文。
4. 运行 `pnpm test`、`pnpm typecheck` 和 `pnpm build:cloudflare`。语言测试检查完整性、占位符、残留源文占位和文字方向声明。
5. 在浏览器检查长按钮、手机布局和 RTL；不要只依靠键数量判断翻译是否完成。

组件通过 `useMessages().tx()` 查找固定文案。运行时错误保留可识别的源消息，在显示时翻译，因此切换语言后已有错误也会更新。不要把用户输入送进翻译流程。

本轮译文由语言模型直接撰写，未经各语种母语审校。欢迎提交用词、语法和地区习惯修正；翻译修改不得弱化密钥传输、浏览器历史、备份和口令不可恢复等说明。

## English contributor notes

All 30 catalogs are local, loaded on demand, and share the same message keys. Preserve interpolation placeholders and technical URI formats. Translate whole sentences, including help, accessibility labels, errors and privacy notices. Do not translate secrets or user-authored labels and notes. Run the source-map sync script, format, tests, typecheck and Cloudflare build after edits. Review mobile and RTL layouts as well as text accuracy.

These translations were authored directly by language models and have not received native-speaker review for every language. Corrections are welcome.
